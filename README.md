# 💧 Controle de Níveis de Água

Projeto desenvolvido em Python para simular o monitoramento de um reservatório de água através do terminal.

## 🚀 Funcionalidades

- Monitoramento de 5 níveis de água.
- Mensagens de alerta coloridas.
- Utilização da biblioteca Colorama.
- Estrutura organizada com funções.

## 🛠️ Tecnologias

- Python
- Colorama
